# CLAUDE.md

Backoffice of NothingEats: a Payload 4 (beta) headless CMS on TanStack Start, the upstream context that owns the shop's content (journal records 040–042). The cross-repo plan and session rules live in `../CLAUDE.md` (workspace root), if present — read it first.

## Commands

- `scripts/dev-env.sh pnpm dev` — admin at http://localhost:3100/admin against the local cluster (secrets from the gitops repo's SOPS files, env only). Needs `kubectl --context k3d-nothingeats -n nothingeats port-forward svc/garage 13900:3900`.
- `pnpm test` / `pnpm lint` / `pnpm typecheck`
- `pnpm build` — `dist/client` (static, under `/admin/assets`) and `dist/server` (srvx entry); Payload packages stay external, so the image ships `node_modules`.
- `scripts/dev-env.sh pnpm generate:importmap` / `generate:types` after adding admin components or fields.

## Rules

- Everything of the admin lives under `/admin` (pages, server functions at `/admin/_serverFn`, assets at `/admin/assets`) and `/api/backoffice`; the shop owns every other path on the same origin.
- No passwords here: admins are identity accounts with role `admin`. The `identity` strategy checks identity's access token (JWKS, issuer, audience) from the `ne_backoffice` cookie or a bearer header; the cookie is scoped to `/admin` and `/api/backoffice`, never `/`.
- Refreshes at identity use the shop's Web Lock `nothingeats-session-refresh`: a refresh token presented twice revokes the whole session family.
- Files under `src/app/_payload*` are generated by Payload; regenerate instead of editing (exception: Google Fonts removed from `_payload.tsx`, the admin loads nothing from third parties).
- Uploads are raster images only (they are served from the shop's origin under `/media`); URLs point at the public variant, never at Payload's file route.
- Payload 4 is a beta: check `payloadcms.com/docs/beta` before assuming v3 behaviour (e.g. `storage: [...]` instead of plugins, `upload.transformers` instead of `sharp`/`imageSizes`).
